## 蜗是符文法师

首先，不难发现最后无法操作时一定是前面一段  $0$ 后面一段 $1$ 的形式，那么我们就需要考虑这四种操作对 $0/1$ 状态的影响。

首先，如果有 $1$ 在 $0$ 的前面，那么肯定会出现第一种情况。考虑用逆序对的形式去刻画操作对 $0/1$ 相对位置关系带来的变化，那么第一种操作会减少一个逆序对，后面三种操作均会减少 $2$ 个逆序对。继续思考，不难发现如果存在两对以上的逆序对，那么后面三种至少存在一种。

因此问题就转化成了最初有若干逆序对，小蜗蜗和大蜗蜗轮流令逆序对数量 $-1$ 或者 $-2$，谁先减到 $0$ 谁就赢了。

这是经典博弈问题，结论是数量是 $3$ 的倍数时后手必赢，否则先手必赢。因为若逆序对数量为 $3$ 的倍数，那么如果先手 $-1$ 后手 $-2$，如果先手 $-2$ 后手 $-1$，每回合逆序对数量都会固定减少 $3$，最后先手就会输掉。如果不是 $3$ 的倍数，先手可先抽掉 $1$ 或 $2$ 使其变为 $3$ 的倍数，这样子攻守异形先手必赢。

## 蜗蜗的重力通道

注意到同一格子内，蜗蜗在变换高度时的方案数可以通过组合数快速求到，然而相邻格子转移时，需要将蜗蜗当前高度坐标存入状态。然而数据很小，$n\le 100,h\le 100$，而高度坐标的转移需要枚举上一高度和当前高度，因此考虑做一个 $\mathcal O(nh^2)$ 的 DP。

设 $f_{i,j}$ 表示蜗蜗当前到了第 $i$ 个格子的右侧，并且高度为 $j$ 的方案数，现在我们想要转移使得蜗蜗能够到达第 $i+1$ 个格子右侧。

首先先把 $j>h_{i+1}$ 的全部舍掉，因为往右走蜗蜗直接撞墙了。然后枚举蜗蜗会转移到最右侧的高度 $k$（$k$ 和 $j$ 的大小关系取决于该格子的重力类型 $o_{i+1}$），方案数是 $\dbinom{l_{i+1}-1+|j-k|}{|j-k|}\times f_{i,j}$。

不过，由于 $l$ 的大小达到了 $10^8$，不可能预处理阶乘之后 $\mathcal O(1)$ 查询了，只能使用暴力求，但是我们不能增加时间复杂度因为现在已经顶满了。

考虑将下指标（即 $|j-k|$）相同的放在一起转移，这样子就只需要每个 $|j-k|$ 求一遍。

```cpp
const LL kMaxN = 105, kMod = 998244353;

LL l[kMaxN], h[kMaxN], o[kMaxN], f[kMaxN], g[kMaxN], t, n;

LL pow(LL a, LL b) {
  LL res = 1;
  for (; b; b /= 2) {
    b % 2 && (res = res * a % kMod);
    a = a * a % kMod;
  }
  return res;
}

LL comb(LL n, LL m) {
  LL res = 1, fac = 1;
  for (LL i = 1; i <= m; i++) {
    res = res * (n - i + 1) % kMod;
    fac = fac * i % kMod;
  }
  return res * pow(fac, kMod - 2) % kMod;
}

int main() {
  cin.tie(0)->sync_with_stdio(0);
  for (cin >> t; t; t--) {
    cin >> n;
    for (LL i = 1; i <= n; i++) {
      cin >> l[i] >> h[i] >> o[i];
    }
    h[0] = h[1];
    fill(f + 1, f + h[0] + 1, 1);
    for (LL i = 1; i <= n; i++) {
      fill(g + 1, g + h[i] + 1, 0);
      for (LL j = 0; j <= h[i]; j++) {
        LL d = (o[i] ? 1 : -1) * j;
        LL b = comb(l[i] + j - 1, j);
        for (LL k = 1; k <= min(h[i - 1], h[i]); k++) {
          LL tar = k + d;
          if (tar < 1 || tar > h[i] || !f[k]) {
            continue;
          }
          g[tar] = (g[tar] + f[k] * b % kMod) % kMod;
        }
      }
      copy(g + 1, g + h[i] + 1, f + 1);
    }
    cout << accumulate(f + 1, f + h[n] + 1, 0LL) % kMod << '\n';
  }
  return 0;
}
```

## 蜗蜗的魔法决斗榜

这道题目在做的时候有几个同学还对题面的歧义提出了异议，便是是否考虑不属于询问区间 $[l,r]$ 作为 $(u,v)$ 中继节点的人。显然是需要考虑的，不然就变成 ZRR 题目了。

首先这种复杂的拥有传递性的指向性关系可以考虑建有向图来描述，在某一个榜单中 $u$ 在 $v$ 前面就可以连一条边 $u\rightarrow v$ 来表述 $u$ 压制 $v$。由于压制关系具有传奇性，没必要每个榜单连 $\mathcal O(n^2)$ 的边，只需要相邻两个连起来即可。

在最终的图当中，$(u,v)$ 互相压制当且仅当 $u$ 和 $v$ 能够互相到达，即它们属于同一个强连通分量，因此考虑 Tarjan 或者两遍 DFS 缩点。显然我 Tarjan 又忘了咋写了因此写的两遍 DFS。

对于每个强连通分量都分配一个颜色，那么对于所有存在于第 $id$ 个榜单 $[l,r]$ 当中对应的颜色每个的出现次数 $c$，答案就是 $\sum\limits_c \dbinom{c}{2}$。

对于前 $70\%$ 的离线测试点，可以直接 $k$ 遍莫队来解决该问题。但是我们有单次 $\mathcal O(1)$ 查询的在线更好的做法。

注意观察，可以发现同一个颜色在某个榜单当中只会出现在一个区间当中，证明如下：考虑 $(u,v)$ 属于同一个强连通分量而且 $(u,v)$ 中间还有点，那么中间任何一个 $w$ 都有 $u$ 能到 $v$，$w$ 能到 $v$，因此某个颜色只会出现于一个区间。

根据这个性质，我们可以分颜色维护 $\dbinom{c}{2}$ 的前缀和，并且记录每种颜色在榜单中的出现区间。查询时，将 $l$ 和 $r$ 的颜色找出来，中间的其它颜色就直接查询前缀和，$l$ 和 $r$ 两遍的没有完全出现的颜色就用记录的颜色区间来计算。

```cpp
const LL kMaxN = 2.5e5 + 5;

LL f[kMaxN], c[kMaxN], id[kMaxN], t, n, k, q, tar, scc;
vector<LL> e[kMaxN], g[kMaxN], s;

void dfs1(LL x) {
  if (f[x]) {
    return;
  }
  f[x] = 1;
  for (LL i : e[x]) {
    dfs1(i);
  }
  s.push_back(x);
}

void dfs2(LL x) {
  if (c[x]) {
    return;
  }
  c[x] = scc;
  for (LL i : g[x]) {
    dfs2(i);
  }
}

LL calc(LL x) {
  return x * (x - 1) / 2;
}

int main() {
  cin.tie(0)->sync_with_stdio(0);
  for (cin >> t; t; t--) {
    cin >> n >> k >> q >> tar;
    vector<vector<LL>> a(k + 1, vector<LL>(n + 1));
    fill(e + 1, e + n + 1, vector<LL>());
    fill(g + 1, g + n + 1, vector<LL>());
    for (LL i = 1; i <= k; i++) {
      for (LL j = 1; j <= n; j++) {
        cin >> a[i][j];
        if (j >= 2) {
          e[a[i][j - 1]].push_back(a[i][j]);
          g[a[i][j]].push_back(a[i][j - 1]);
        }
      }
    }
    s.clear();
    fill(f + 1, f + n + 1, 0);
    fill(c + 1, c + n + 1, 0);
    for (LL i = 1; i <= n; i++) {
      dfs1(i);
    }
    scc = 0;
    for (LL i = n - 1; i >= 0; i--) {
      if (!c[s[i]]) {
        scc++;
        dfs2(s[i]);
      }
    }
    vector<vector<LL>> id(k + 1, vector<LL>(scc + 1)), pre(k + 1, vector<LL>(scc + 1)), lft(k + 1, vector<LL>(scc + 1)), rgt(k + 1, vector<LL>(scc + 1));
    for (LL i = 1; i <= k; i++) {
      LL cnt = 0;
      for (LL j = 1; j <= n; j++) {
        LL &pid = id[i][c[a[i][j]]];
        if (!pid) {
          pid = ++cnt;
        }
        pre[i][pid]++;
        if (!lft[i][pid]) {
          lft[i][pid] = j;
        }
        rgt[i][pid] = j;
      }
      for (LL j = 1; j <= cnt; j++) {
        pre[i][j] = pre[i][j - 1] + calc(pre[i][j]);
      }
    }
    for (LL x, l, r, ans = 0; q; q--) {
      cin >> x >> l >> r;
      if (tar) {
        x = (x + ans) % k + 1;
        l = (l + ans) % n + 1;
        r = (r + ans) % n + 1;
        if (l > r) {
          swap(l, r);
        }
      }
      LL wyy = id[x][c[a[x][l]]], zrr = id[x][c[a[x][r]]];
      if (wyy == zrr) {
        cout << (ans = calc(r - l + 1)) << '\n';
      } else {
        cout << (ans = calc(rgt[x][wyy] - l + 1) + (pre[x][zrr - 1] - pre[x][wyy]) + calc(r - lft[x][zrr] + 1)) << '\n';
      }
    }
  }
  return 0;
}
```
